# 随网站部署的英音录音

Task Mode：design-build。Outcome Status：complete。日期：2026-09-29。
用户已确认采用“现成英音录音优先，缺失项补录或合成”的方案，并授权修改项目。本设计在实现前建立，适用于发音资源与播放器生命周期变化。

## 目标、证据与边界

目标是让内置 161 项在没有系统语音库的现代浏览器中也能使用同一份英音音频，保留次数、间隔、暂停、重播、导入和错词复习。
操作者为学生，维护者为准备词表的家长；资源准备发生在发布前，练习时不调用外部 TTS，不增加账户、后端、付费服务或上传导入文件。
成功信号是全部内置项有可解码资源、无 speechSynthesis 时能连续播放、保存兼容且取消后无迟到播放；失败信号是暗中切换美音/系统声音或资源缺失仍推进队列。
“任意 OS”限定为支持 Web Audio 和网站运行要求的现代浏览器，不承诺所有历史 OS/浏览器，也不声称桌面浏览器验证等价于真实 iPad 音质和锁屏体验。

## 概念与决定

录音目录是英文项到本地音频路径的映射，不依赖词源 ID；同一英文导入后能复用资源。每项标注真人/合成、英式口音、原始页面、作者、许可或生成声音。
目录匹配统一使用小写、首尾裁空白、内部空白合并及弯引号转直引号。正式队列是当前组选项或错词集合；试听是一次临时朗读，不替换队列、位置、次数和间隔。暂停期间禁止试听以保留剩余时间；试听样本使用已收录的 guitar，不使用未收录的整句。音频驱动只拥有当前加载请求及一个 AudioBufferSourceNode；播放器继续拥有阶段、generation 和等待 timer。

## 逻辑链与架构判断

- LC-A1：因为 OS 开放的声音不一致，所以把确定的英音作为静态资源随网站交付。
- LC-A2：因为教材词表有限且已有开放录音，所以先匹配真人录音，少量或未找到项才合成；记录实际覆盖而非推断全部存在。
- LC-A3：因为下载、解码和音频结束均异步，所以取消必须同时失效播放器和音频驱动的 generation，清理请求和 source；迟到结果不能播放。
- LC-A4：因为试听不是练习，所以试听只拥有临时项，不能改变主队列或节奏。
- LC-A5：因为现有词表/错词记录不需要声音文件进入存储，所以音频目录独立于 snapshot，保持 v1 兼容和损坏保护。

主线仍是纸上听写；来源筛选、许可说明和构建是发布支持。音频资源不进入用户导入文件和快照，不引入通用媒体框架或运行时外站依赖。
Selected Check IDs：AA-RUNTIME、AA-DELIVERY。
AA-RUNTIME：播放器与音频驱动各拥有自身失效标识；音频结束只进入一次下一阶段；暂停朗读重读当前遍，等待保留剩余时间。加载和解码也处在可暂停阶段，取消后不能响。
AA-DELIVERY：下载/生成脚本只写 public/audio 下的资源和清单；Vite 仍是 dist 唯一生成者。构建不联网，根路径/子路径均使用相对资源地址；来源许可与音频一起部署。

## 状态、错误、性能和隐私

既有阶段不变：idle、speaking（含加载）、repeat-gap、writing-gap、paused、complete、error；新增临时试听标识，试听完成回 idle，主位置不变。
点击开始/继续/重播同步请求解锁音频 context；异步加载失败、解码失败、resume/play 拒绝和超时进入 error，当前位置与队列保留，不切换系统声音。
取消先失效回调，再 abort fetch、解绑 ended、stop/disconnect source；context 复用于后续点击。解码缓存有界，后台暂停后前台必须用户点击恢复。
正式开始前检查本组资源覆盖；单项复习仍能播放已覆盖项。缺失提示在听写模式只显示数量，避免泄露答案。
导入文件和英文词条不上传；浏览器只请求同站资源。外部语音服务仅在维护者显式运行准备脚本时使用；普通 build/dev 不触发下载或合成。
