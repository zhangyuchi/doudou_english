# 停用网页词表导入

用户要求停用网页导入功能；本次修改同步发布到 qqvps 的现有 80 端口站点。

网页移除导入按钮、对话框及相关事件处理。仅禁用按钮会保留不可用的入口和整套导入窗口，增加维护负担；本次直接移除浏览器交互。共享的词表解析、验证和命令行导入继续使用原实现。

服务器发布的词表、标准与精品声音、复习、听写、返回内置词表和错词保存保持原行为。已有浏览器快照继续恢复，不迁移或清空记录。命令行 TXT/CSV/PDF 导入继续生成音频、发布词表并构建网站。

浏览器回归验证没有导入入口且声音可播放，并通过旧快照验证自定义词表和错词仍可恢复。原先通过网页导入创建测试词表的场景改为加载快照；PDF 解析由已有真实 PDF 和命令行测试验证。部署检查同步验证无导入控件。发布后检查公网没有导入入口、161 项 Luna 音频可下载解码，并抽样实际播放。
