# 阿里云个人学习音频生成与播放

Task Mode: design-build。日期：2026-09-30。文档状态：实现与模拟验证完成。Outcome Status: complete（交付范围为代码及模拟验证）。

## 证据、目标和范围

- E-1：当前 `src/audio.js` 按标准化英文查找同站音频，`src/app.js` 协调声音选择；`src/player.js` 已统一结束、暂停和取消契约。实施前工作区干净。此证据不证明阿里云实际返回数据或真机音质。
- E-2：`src/import.js` 已提供 TXT/CSV 校验和完整短语解析；内置词表为 161 项。复用解析，不在命令行解析 PDF。
- E-3：2026-09-30 核对阿里云 [REST 文档](https://help.aliyun.com/zh/isi/user-guide/restful-api-3) 与 [Token 文档](https://help.aliyun.com/zh/isi/user-guide/obtain-an-access-token)：上海 HTTPS、POST JSON、Appkey/NLS Token、WAV/MP3；通过官方 `@alicloud/pop-core` SDK 调用 CreateToken 并按 ExpireTime 刷新。
- E-4：用户限定为自己的英语学习，不对外提供；公开商业短文本协议限制个人或企业内部使用。阿里云音频不声明 CC0，也不加入原开放音频清单。

目标：用户配置凭证后，能从内置或 TXT/CSV 词表生成本地音频，网页可明确选择该声音并对应播放。成功信号为真实脚本协议请求、逐项可恢复落盘、网页匹配与解码播放；此任务的交付范围是脚本和页面实现及模拟服务验证，真实账号合成需用户开通后运行。非目标：部署、对外授权、美式声音、在线实时 TTS、改变听写状态机、自动判断多读音。

操作者及受益者为用户；用户承担真实 API 调用费用。已知输入和播放器契约可复用；未知账号权限、实际音质、网络和额度仅能通过用户后续运行验证。实施约束：凭证只来自本地环境文件；默认预览无网络，显式 `--execute` 才申请 Token 和合成；现有录音和许可证不改写。

## 概念、方案和逻辑链

词表项是单词或完整短语；生成配置是英式音色与语速；生成清单是唯一已成功音频索引；阿里云英音是可选择的本地声音，而非浏览器运行时 API。标准化规则复用 normalizeWord；同一配置中重复英文只合成一次。现有英文键只能表示一种读音，歧义词须人工试听后调整词表，不声称自动消歧。

| 决策  | 选择及理由                                                                    | 替代及重新评估条件                                                      |
| ----- | ----------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| DEC-1 | 离线维护脚本配合同站音频，保持网页静态部署及无凭证                            | 网页直接调用会暴露凭证且每次收费；需要在线任意新词时另行设计            |
| DEC-2 | 阿里云独立目录和选项，缺词阻止整组，保留旧声音                                | 替换原音频会混淆许可且难以回滚；不采用                                  |
| DEC-3 | 官方 SDK 申请 Token，内置 fetch 合成；顺序请求，无自动付费重试                | 手写签名无现有收益；多并发增加额度和失败复杂性                          |
| DEC-4 | WAV 供已有 Web Audio 解码；Vite 配置在启动/构建时读取可选非敏感清单并注入网页 | 运行时抓取缺省清单增加启动和取消竞态；public 内 JSON 不作为源码模块导入 |

- LC-1：因为练习只需重复播放文件，所以收费 API 只存在于脚本，网页使用原播放器。
- LC-2：因为失败后重跑不能重复生成已成功项，所以用配置和英文的哈希命名，校验文件哈希和内容后跳过，逐项原子提交清单。
- LC-3：因为新词可能不完整，所以单独选择阿里云声音且保留整组覆盖检查，失败不静默切声。
- LC-4：因为合成文件仅供个人学习，所以与开放音频及许可页面分离，并忽略 Git 中的私人产物。

架构主线是词表 → 顺序合成 → 文件及清单 → 明确选声 → 原播放器。配置、收费和生成不进入产品界面；网络错误不掩盖为成功。高级检查选择 AA-RUNTIME / AA-DELIVERY：脚本锁避免两进程写同目录；构建与生成不得并行；全部静态资源随 dist 交付，私人产物不上传公开网站。

## 文件、状态与恢复契约

`public/audio/aliyun/manifest.json` 格式为 `{version:1, voice, speechRate, entries:[{english,file,sha256,bytes,generatedAt}]}`。文件是由配置和英文计算的哈希 WAV；清单没有凭证，只索引成功项。已有清单配置不符则拒绝写入，以免混声。缺失或损坏的文件在明确执行后重新合成。文件先写临时文件再 rename，随后原子提交清单；如果恰好在二者之间崩溃，会留下未索引文件，重跑可能重复收费一次，不谎称实现跨文件事务。每次执行持有独占目录锁；正常退出释放，意外退出遗留锁需确认无运行进程后人工删除。

默认仅预览去重词数、已有项与按普通 TTS 起步价估算的新请求费用；无需凭证、没有网络。`--execute` 时从环境获取 Appkey、AccessKey，亦支持已有临时 Token；Token 仅在内存缓存。每项以 POST JSON 请求，30 秒超时，检查 HTTP、音频 MIME 及 WAV 结构，不保存 JSON 错误。失败停止并保留成功结果，诊断不输出凭证或完整响应。SIGINT 中止合成并保留已提交结果；没有自动付费重试。

WAV 校验包括 RIFF 总长、各块边界、PCM 声道/采样率/位深、块对齐/字节率一致性和完整数据帧。官方 SDK 的 HTTP 调试日志会包含签名请求和 Token，因此顺序脚本在申请 Token 时暂时禁用 SDK 及 httpx 的 debug 实例，响应读取后恢复；不同 debug 版本的设置必须在任何禁用操作前一起保存。

网页由 Vite 配置读取可选 manifest，未生成音频时无新增选项；已有时增加阿里云英音。生成后需重启开发服务或重新构建。当前声音选择决定驱动，cancel 同时取消两个驱动，沿用原播放器；试听从当前可播放词表选择样本，避免只依赖 guitar。显示新声音的覆盖数量，缺失项保持禁用。
