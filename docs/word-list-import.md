# 在 iPad 导入自己的单词文件

网页可以导入文字 PDF、TXT 或 CSV。文件在 iPad 浏览器本地读取，**不会上传服务器**；部署脚本与单词导入无关，也不需要把个人词表放进服务器发布目录。

在本机维护网站时，也可用[阿里云词表与英音命令](aliyun-audio.md)读取同样三种格式，先生成并保存音频，再发布为网页刷新后自动出现的词表。该命令会向阿里云发送英文词项，仅在显式添加 `--execute` 时执行；网页手动导入始终只在浏览器本地解析。

精品英音加 `--quality premium`，例如 `npm run import:aliyun -- --quality premium --input words.csv --execute`；需填写北京百炼凭证。省略 `--input` 会补齐最近由命令发布的词表，同一词表切换音频品质保留错词。详见[精品接入](aliyun-audio.md#精品英音百炼)。

## 导入与核对

1. 把单词文件保存到 iPad“文件”应用可访问的位置，例如“我的 iPad”、iCloud 云盘或下载目录；云盘文件需能正常下载读取。
2. 在 Safari 打开听写网页，点击“导入”，再点“＋ 选择单词文件”，选中 PDF、TXT 或 CSV。
3. 等待“文件已读取”，检查“预览与修正”里的英文、中文和空行分组。可修改词表名称，直接修正识别结果。
4. 查看组数、总项数和每组数量，必要时点击“每 15 项重新分组”，或编辑空行自行分组。
5. 确认内容正确后点击“确认使用词表”，再选择分组开始复习或听写。

**确认新词表会替换当前词表，并清空上一份词表的错词记录。** 点击“取消”或关闭导入窗口，不改变当前词表；解析失败也不会替换。网页只保存一份当前词表，不是多词库管理器。

## PDF：支持什么排版

支持具有文字层的中英词表，尤其是项目附带的[外研社七年级词表](../public/examples/外研社7年级英语听写分组.pdf)。当前样例为 11 组、161 个听写项，一个完整短语算一项。

- 应能选中或复制 PDF 里的文字；扫描照片、图片 PDF 需先做 OCR，网页没有内置 OCR。
- 当前解析针对英文加中文释义，通过位置与留白恢复分组；多栏、表格或特殊排版可能需要在预览修正。
- 只有英文的 PDF 不属于当前解析目标；可把英文整理成 TXT 或 CSV 再导入。
- 只有编号和录音按钮的听写 PDF 没有词表，不适合作为单词源。不会提取或使用 PDF 内的录音。

如果预览缺词、释义混合或分组不准，确认前修正；不要把“文件读取成功”当成所有内容准确的保证。

## TXT：一行一个词或短语

推荐保存为 UTF-8 的纯文本 .txt 文件，不是 Word 文档改后缀。格式为“英文 + 实际 Tab + 可选中文”，空行分组；只有英文也可以。

下面英文与中文之间是实际 Tab，可直接参考可下载的 [words.txt 样例](../public/examples/words.txt)：

```text
hello	你好
primary school	小学

point out	指出
```

primary school 和 point out 会各自保留为一个听写项，不按空格拆词。不要把 Tab 写成反斜杠加字母 t（即 `\t`）。在电脑编辑文本时可按 Tab 键；iPad 不便输入 Tab 时可以只写英文，再在网页预览补释义。

## CSV：适合电子表格维护

按固定顺序使用英文、中文、组号三列；组号可省略，中文可为空。推荐表头 english,chinese,group，从 Excel/Numbers 导出 UTF-8 CSV。不要上传 .xlsx 或 .numbers 文件。

[words.csv 样例](../public/examples/words.csv)：

```csv
english,chinese,group
hello,你好,1
primary school,小学,1
point out,"指出,指明",2
```

相同组号会归为同组，按组号首次出现的顺序排列；不自动按数字大小排序。中文有逗号时用双引号包住，例如“指出,指明”。解析预览里的标题统一显示为“第 1 组”等，分组边界仍保留，不保留 CSV 组号作为显示名称。

## 分组、范围与保存

- 每组数量不固定。只有一组且超过 15 项时，导入预览会自动按 15 项分组；多组原有边界默认保留。
- 点击“每 15 项重新分组”会合并现有项再按 15 项分组，末组可少于 15 项。需要自定义数量，直接编辑预览中的空行。
- 每个文件最多 20 MB；PDF 最多 100 页；每份词表最多 2000 项。
- 英文支持单词、空格连接的短语以及撇号、连字符、点号；不能包含数字或其他符号，单项英文最长 100 个字符，中文最长 500 个字符。
- 设置、当前词表和错词保存在当前浏览器与网站 origin（协议、域名、端口）对应的 localStorage 中，不同步到服务器或其他设备。清理网站数据会丢失记录；请保留原始词表文件。
- 保存失败时页面会提示，本次仍可练习，但不能保证刷新后恢复。浏览器存储不是永久备份。

要重新使用项目词表，点击“返回内置词表”并确认；这也会清空当前词表的错词记录，不保留上一次导入词表。

## 常见问题

| 问题                   | 处理                                                                                         |
| ---------------------- | -------------------------------------------------------------------------------------------- |
| 选不到文件             | 先在“文件”应用确认文件能打开，检查扩展名为 .pdf/.txt/.csv；云盘文件需下载完成                |
| PDF 没识别到单词       | 检查能否复制文字、有无中文释义；扫描件先 OCR，纯英文列表改用 TXT                             |
| 中文乱码               | 用 UTF-8 重新保存 TXT/CSV，不要直接改后缀                                                    |
| CSV 提示列数或引号错误 | 确保最多三列，中文逗号用双引号包住；确认导出分隔符是英文逗号                                 |
| 分组数量不对           | 查看空行，可手动改或按 15 项重新分组，确认后才生效                                           |
| 确认按钮不可用         | 检查预览错误提示，移除非法字符、空白英文项或超长内容                                         |
| 导入后没有声音         | 先查看预置英音覆盖数量；新词未收录时可主动选系统英音或补充网站录音。词表导入不会自动生成音频 |
| 换网站地址后记录消失   | 协议、域名或端口改变会使用另一份存储；在原地址查看，必要时重新导入原文件                     |

服务器部署见[部署指南](deployment.md)，回滚服务器文件不会回滚 iPad 的词表与错词。
