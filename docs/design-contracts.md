## 证据与目标

E-1：原词表经 pdftotext 提取，11 组、161 项（10，九组 15，16），适用于当前词表，不证明任意 PDF 格式都可准确识别。
E-2：用户明确选择 iPad Safari、纸上作答、朗读默认 1 次可选 1/2/3、间隔默认 10 秒、PDF 导入和独立部署。
E-3：SpeechSynthesis 的语音列表及结束事件为浏览器接口；实际声音和暂停行为依赖设备。依据 MDN 的 getVoices、end、pause 文档，不能据桌面自动测试宣称真机音质。
E-4：PDF.js 支持文件解析；文字项带坐标。采用库解析 PDF，不实现自制 PDF 解码器。Node 24.15.0 和 npm 11.12.1 可用。

目标：学生能以英音逐项听写内置和导入的词表，按自己节奏纸上作答、核对、复习错词。成功信号是实际词表正确导入、状态取消无串播、英音选择明确、部署产物独立。非目标是 OCR、录音素材、离线、账户和自动批改。

操作者是学生，维护者是部署网页的家长。成本主要是首次部署及声音试听；不引入服务器费用或语音 API 密钥。

## 概念、决定与逻辑

词源：一份可选择的词表，含标题、分组和稳定项标识。听写项：一个单词或完整短语，含英文、可选中文。队列：一次练习的有序项集合。错词：当前词源内项标识集合。播放阶段：idle、speaking、repeat-gap、writing-gap、paused、complete、error。

LC-1：因为纸上作答，所以网页只需管理发音和节奏，不需要答题输入或评分服务。
LC-2：因为用户需要任意新词的英音，所以选择实际可用的 en-GB 系统声音，而不依赖固定录音或默认语言。
LC-3：因为 speech 和 timer 都可能在取消后产生事件，所以所有异步动作归同一个播放器所有，用递增 generation 忽略旧事件。
LC-4：因为 PDF 没有词表语义，所以用坐标恢复阅读顺序、中文分隔识别条目、留白识别分组，确认前提供可编辑预览。
LC-5：因为错词和词源可能同时更新，所以用同一版本化快照原子保存，解析失败不覆盖当前状态。

DEC-1：选择浏览器英音，拒绝原录音素材（用户已决定）；若音质不满意再另行讨论预生成英音。
DEC-2：选择 Vite 构建静态资源，PDF.js 自带 worker 和字体资源随 dist 一起部署；拒绝运行时 CDN，防止 PDF 导入依赖外站。
DEC-3：选择单一词源快照并提供内置词表返回入口；每次确认导入建立新词源和独立错词集合，旧词源快照在成功保存后替换。确认界面明确说明将切换词表并清空旧词表错词，避免静默丢失。用户取消或导入失败不变。

主线是听写，导入和核对支持主线。声音选择与词表解析正交；UI 不拥有底层定时器。性能约束为文件最大 20 MB、最多 100 页、最多 2000 项，超限提示保留旧数据。

Selected Check IDs: AA-RUNTIME、AA-DELIVERY。
AA-RUNTIME：浏览器事件循环驱动语音与 timer，PDF worker 仅负责解析；取消先失效 generation，再 cancel 和清除 timer，不产生重叠队列。
AA-DELIVERY：Vite 是 dist 的唯一生成者，字体复制由构建脚本写入 public/pdfjs，部署整体 dist，base 使用相对路径，支持子目录托管；静态文件与本地快照不要求服务器迁移。

## 状态、数据与错误契约

播放器拥有唯一 utterance 与唯一等待 timer。最后一遍的 end 才启动完整书写间隔；最后一项也等待后完成。重复之间等待 1 秒。暂停保存阶段、剩余等待和重复计数；朗读中取消当前遍，点击继续后重读该遍，以免截断单词或依赖系统不一致的 pause/resume 行为。切后台自动暂停，回前台由用户点击继续。设置仅在非运行状态可改，改后取消旧播放并重置当前项。切换模式、项、声音、词源均取消旧动作。

localStorage 键 ipad-dictation:v1 保存 {version:1, settings:{repeat,interval,voiceURI}, source:{id,title,groups:[{label,items:[{id,english,chinese}]}]}, mistakes:[id]}。恢复时验证完整数据和设置范围；损坏快照不覆盖，界面告知只读回退到内置词表，需明确选择重新保存才替换。不解释未知版本。写失败保持本次内存练习并提示未保存。

导入文件只在浏览器读取，文本以 textContent/input.value 展示。CSV/TXT 是额外便捷格式，与 PDF 共用条目验证和预览；不执行输入的 HTML。重复英文保持独立项标识，不据英文单独合并。预览用“英文 TAB 中文”、空行分组，支持直接编辑和按 15 项重新分组。未确认不能改变词源；二次导入和关闭预览使旧解析任务失效。无文本、无英文加中文的词表、扫描件、解析错误均给出可操作提示。

发音错误进入 error，不能推进下一项；支持点击重播。英音缺失禁用发音但保留复习、核对与导入。声音列表异步到达时刷新，不能改用 en-US。
